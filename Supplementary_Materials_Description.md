# Supplementary Materials

## Supplementary Data 1

`Data/Actuator_Product_Dataset.xlsx` contains 176 finalized actuator-product records with an English data dictionary.

## Supplementary Data 2

`Data/Joint_Task_Requirements.xlsx` contains eight static hip and knee task envelopes used in the case study.

## Supplementary Results 1-5

The `Results` folder contains selected aggregate tables and figures for grouped validation, calibration, scoring sensitivity, and fair LLM comparison.

## Supplementary Code 1

The `Code` folder contains a no-API script for inspecting the released data and results. It does not distribute credentials, raw LLM outputs, or reviewer-blinding materials.
